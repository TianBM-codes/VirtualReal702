# 有限元后处理平台性能优化简报

汇报日期：2026年10月15日　实测日期：2026年10月13日

本轮针对约50万节点模型开展优化前后对比。已解析模型的首次数据读取由约0.41秒降至0.31秒；材料与截面分类、图例、数量统计等操作的等待时间明显缩短，多项重复操作由数秒降至1秒以内。模型导入就绪的总耗时基本持平，同时修复了区域单元边线返回空数据的问题。

## 模型导入与加载

“导入”是将模型文件和结果解析为可查看的数据；“读取模型”是取得已解析的三维模型数据。下表的读取时间包含后端接口处理和完整数据下载，不含浏览器绘制。单位：秒。

| 操作 | 优化前 | 优化后 | 本轮变化 |
|---|---:|---:|---|
| 模型与结果全部导入就绪 | 41.33 | 40.34 | 基本持平 |
| 模型几何及后台索引全部就绪 | 33.10 | 33.16 | 基本持平 |
| 已解析模型首次读取 | 0.410 | 0.306 | 耗时减少25.4% |
| 已解析模型重复读取 | 0.343 | 0.317 | 耗时减少约7.6% |
| 首次取得变形结果 | 1.73 | 1.43 | 耗时减少17.2% |
| 重复取得动画数据 | 0.466 | 0.455 | 基本持平 |

重复读取变形结果均约0.26秒；重复读取模态振型由0.139秒增至0.160秒，增加约21毫秒。这些指标没有出现与分类操作同等幅度的改善。

## 分类查看与云图对比

以下为同一模型重复请求的耗时中位数，包含完整响应数据下载。单位：秒。

| 典型操作 | 优化前 | 优化后 | 耗时减少 |
|---|---:|---:|---:|
| 按材料上色 | 6.11 | 0.20 | 96.8% |
| 按截面区域上色 | 5.91 | 0.25 | 95.7% |
| 查看材料图例 | 4.60 | 0.03 | 99.4% |
| 查看截面区域数量统计 | 11.10 | 0.87 | 92.2% |
| 显示全部单元边线 | 1.41 | 0.11 | 91.9% |
| 查看材料区域轮廓 | 5.17 | 0.51 | 90.2% |
| 显示分片云图 | 0.92 | 0.22 | 75.7% |

上述典型操作的重复请求耗时减少约76%至99%，其中图例、分类上色和数量统计的改善最明显。分类操作的首次请求仍可能需要数秒。

## 问题修复与后续建议

区域单元边线原先返回空数据，修复后可正常返回约100.5万条边线。由于新旧版本返回内容不同，本项不计算性能提升比例。当前该操作仍约需3.3秒，建议后续重点优化区域筛选和边线去重。

## 验证范围

两版各覆盖38项测试场景，共完成264次基准请求；30项相关功能回归测试全部通过。覆盖单元类型、材料、截面类型、截面区域及截面指派五种分类，以及相关图例、统计、区域边线和轮廓。

测试在同一台机器上按版本顺序执行，使用同一50万节点圆柱模型，关闭后台自动预热。首次读取指脚本本轮观察到的首次接口请求，不代表浏览器首次打开的总时间。重复读取及新增分类明细的中位数取首次之外的后两次请求；每种分类的区域测试选取一个最大可见区域。结果反映本次样本，仍需更多模型验证。表中数值已四舍五入，降幅按原始数据计算。

数据来源：2026年10月13日完整基准测试报告。代码及修复已提交推送。

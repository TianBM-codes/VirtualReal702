## 一、分量约定（所有公式的前提）

输入张量分量顺序按 Abaqus 约定：

```
comp[0]=S11  comp[1]=S22  comp[2]=S33  comp[3]=S12  comp[4]=S13  comp[5]=S23
```

- **6 分量（实体单元）**：11, 22, 33, 12, 13, 23 全有
- **4 分量（壳 / 膜单元）**：只有 11, 22, 33, 12，此时令 **S13 = S23 = 0**
- 记号：`p = (S11+S22+S33)/3`（平均正应力）；偏量 `Sij_dev = Sij − p·δij`
- 主应力 `λ₁ ≤ λ₂ ≤ λ₃` = 下面对称张量 T 的特征值（`numpy.linalg.eigvalsh`，升序）：

```
        | S11  S12  S13 |
   T =  | S12  S22  S23 |     的特征值
        | S13  S23  S33 |
```

## 二、各不变量公式（代码原文）

| 不变量 | 代码公式 |
|---|---|
| **MISES** | `√( 0.5·[ (S11−S22)² + (S22−S33)² + (S33−S11)² + 6(S12²+S13²+S23²) ] )` |
| **PRESS**（压力） | `−(S11+S22+S33)/3` |
| **MAX_PRINCIPAL** | `λ₃`（最大特征值） |
| **MID_PRINCIPAL** | `λ₂` |
| **MIN_PRINCIPAL** | `λ₁`（最小特征值） |
| **TRESCA** | `λ₃ − λ₁` |
| **MAX_PRINCIPAL_ABS** | 当前代码：`max(\|λ₁\|, \|λ₃\|)`（无符号，恒 ≥ 0）**← 错，见 ③** |
| **INV3**（第三不变量） | `det(S_dev)` = `d11·(d22·d33 − S23²) − S12·(S12·d33 − S23·S13) + S13·(S12·S23 − d22·S13)`，其中 `d11=S11−p, d22=S22−p, d33=S33−p` |
| **MAX_INPLANE_PRINCIPAL** | `(S11+S22)/2 + √( ((S11−S22)/2)² + S12² )` |
| **MIN_INPLANE_PRINCIPAL** | `(S11+S22)/2 − √( ((S11−S22)/2)² + S12² )` |

| **OUTOFPLANE_PRINCIPAL** | `S33`（面外方向直接取 S33） |
| **MAGNITUDE**（向量场用，如位移 U） | `√( Σ comp² )` |

## 三、待与 Abaqus 口径确认 / 修正的点

### ① INV3 —— 可能存在定义不一致 ⚠️

当前代码 `INV3 = det(S_dev)`，即偏应力第三不变量 **J₃**。

而 Abaqus 输出变量中的 "Third Invariant" 定义带立方根与系数：

```
Abaqus INV3 = ( 9/2 · S·S·S )^(1/3) = ( 27/2 · J₃ )^(1/3)
```

即 Abaqus 报的是 `(27/2 · det(S_dev))` 再开三次方，量纲为应力¹；
我们目前只报 `det(S_dev)` 本身，量纲为应力³。**数值与量纲都对不上。**

→ 若按 Abaqus "Third Invariant" 口径，本条公式需改为 `(27/2 · J₃)^(1/3)`。等确认。

### ② 主应力 —— 公式正确，但节点处口径需对齐

主应力用全张量特征值计算，数学上正确。差异仅在**外推位置**：

- **积分点（INTEGRATION_POINT）**：直接从张量算，两边一致。
- **单元节点 / 节点（ELEMENT_NODAL / NODAL）**：
  - 我们：先把张量外推到节点，再算不变量（**方法 B**）。
  - Abaqus 云图默认：先在积分点算好标量不变量，再外推该标量（**方法 A**）。
  - 对主应力这类非线性量，两者在节点上**本就有差**（方法 A 会过冲）。

→ 这是口径选择，不是算错。需确认节点处采用方法 A 还是方法 B。

### ③ 所有 Abs 变体 —— 应为「带符号」，目前写成了无符号 ❌

领导反馈：Abs 云图里**存在负值**。说明 Abaqus 的「Max. Principal (Abs)」是
**带符号**的——挑绝对值最大的那个主值，但**保留它原来的正负号**：

```
MAX_PRINCIPAL_ABS         = λ₃  若 |λ₃| ≥ |λ₁|，否则 λ₁      （保留符号）
MAX_INPLANE_PRINCIPAL_ABS = 面内max 若 |面内max| ≥ |面内min|，否则 面内min
```

当前代码用的是无符号幅值 `max(|·|, |·|)`（恒 ≥ 0），在**压应力主导**区域
（绝对值最大者为负的主值）会把负值显示成正值，与 Abaqus 云图不符。

> 备注：早前在 door 模型探测时，`getScalarField(MAX_PRINCIPAL_ABS)` 值域恰为
> `[0, 7.764]`，是因为该模型受载区一直是拉应力主导（绝对值最大者始终是正的 λ₃），
> 没触发翻负号的情形，被误判为「无符号」。实为带符号。

→ 修正：把 `np.maximum(np.abs(a), np.abs(b))` 改回带符号的
`np.where(np.abs(a) >= np.abs(b), a, b)`。

### ④ 应变场切应变分量 —— 缺 ÷2（工程剪应变 vs 张量剪应变）❌

`_compute_invariants_numpy()` 不区分应力 / 应变，剪切分量一律当张量分量直接用。

但 Abaqus 应变场（E / LE / NE / PE …）输出的剪切分量是**工程剪应变**
`γ₁₂ = 2·ε₁₂`。组装应变张量求主应变 / Tresca / INV3 / 面内主应变 / Abs 时，
必须先把 12 / 13 / 23 三个剪切分量 **÷2** 还原成张量剪应变 `ε = γ/2`，否则结果整体偏大。
应力场不受影响（应力剪切 σ₁₂ 本就是真张量分量）。

影响范围：
- 积分点（IP）走 Abaqus `getScalarField`，Abaqus 内部已处理，**正确**；
- 单元节点 / 节点（EN / NODAL）走 numpy 重算，**应变全部偏大**；
- numpy 专属不变量（如面内 Abs）即便在 IP 也由我方算，应变同样受影响。

→ 修正：对应变类场，组张量前 `c12, c13, c23 /= 2`。一处改动，下游所有公式自动正确
（含 Mises 项 `6·γ² → 6·(γ/2)²`）。

待确认：应变类场清单（E, LE, NE, PE, EE, IE, THE, CE …是否全算）、
以及 Mises/等效应变是否要匹配 Abaqus 带 2/3 因子的等效应变定义。

## 一、分量约定（所有公式的前提）

输入张量分量顺序按 Abaqus 约定：

```
comp[0]=S11  comp[1]=S22  comp[2]=S33  comp[3]=S12  comp[4]=S13  comp[5]=S23
```

- **6 分量（实体单元）**：11, 22, 33, 12, 13, 23 全有
- **4 分量（壳 / 膜单元）**：只有 11, 22, 33, 12，此时令 **S13 = S23 = 0**
- 记号：`p = (S11+S22+S33)/3`（平均正应力）；偏量 `Sij_dev = Sij − p·δij`
- **应变场（E/LE/NE/PE/EE/IE/THE/CE/VE/SE）**：Abaqus 输出的剪切分量是工程剪应变
  `γ = 2ε`，组张量前先 `S12,S13,S23 ÷ 2` 还原成张量剪应变 ε；应力场不除。
- **Mises 只对应力场计算**，应变场不生成 Mises。
- 主应力 `λ₁ ≤ λ₂ ≤ λ₃` = 下面对称张量 T 的特征值（`numpy.linalg.eigvalsh`，升序）：

```
        | S11  S12  S13 |
   T =  | S12  S22  S23 |     的特征值
        | S13  S23  S33 |
```

## 二、各不变量公式（代码原文）

| 不变量 | 代码公式 |
|---|---|
| **MISES**（仅应力） | `√( 0.5·[ (S11−S22)² + (S22−S33)² + (S33−S11)² + 6(S12²+S13²+S23²) ] )` |
| **PRESS**（压力） | `−(S11+S22+S33)/3` |
| **MAX_PRINCIPAL** | `λ₃`（最大特征值） |
| **MID_PRINCIPAL** | `λ₂` |
| **MIN_PRINCIPAL** | `λ₁`（最小特征值） |
| **TRESCA** | `λ₃ − λ₁` |
| **MAX_PRINCIPAL_ABS** | `λ₃ 若 \|λ₃\| ≥ \|λ₁\|，否则 λ₁`（**带符号**，可为负） |
| **INV3**（第三不变量） | `cbrt( 27/2 · J₃ )`，其中 `J₃ = det(S_dev) = d11·(d22·d33 − S23²) − S12·(S12·d33 − S23·S13) + S13·(S12·S23 − d22·S13)`，`d11=S11−p, d22=S22−p, d33=S33−p`。等价 `(9/2·S·S·S)^(1/3)` |
| **MAX_INPLANE_PRINCIPAL** | `(S11+S22)/2 + √( ((S11−S22)/2)² + S12² )` |
| **MIN_INPLANE_PRINCIPAL** | `(S11+S22)/2 − √( ((S11−S22)/2)² + S12² )` |
| **MAX_INPLANE_PRINCIPAL_ABS** | `面内max 若 \|面内max\| ≥ \|面内min\|，否则 面内min`（**带符号**，可为负） |
| **OUTOFPLANE_PRINCIPAL** | `S33`（面外方向直接取 S33） |
| **MAGNITUDE**（向量场用，如位移 U） | `√( Σ comp² )` |

> 应变场计算上表所有项前，先把 S12/S13/S23 替换为 ε = γ/2（÷2）。Mises 不对应变计算。

## 三、修正记录与待确认项

> 领导 2026-06-26 反馈口径已落实：① INV3 改 Abaqus 口径、③ Abs 改带符号、
> ④ 应变剪切 ÷2、Mises 只算应力。下列 ①③④ **已改入代码**，② 保持现状待定。
> 纯 numpy 算例已验证三处公式正确（Abs 保号 / INV3 = (9/2·SSS)^(1/3) / 应变 γ=2ε 主值减半）。

### ① INV3 —— 已修正 ✅

原 `INV3 = det(S_dev) = J₃`（量纲应力³），与 Abaqus "Third Invariant" 不符。
Abaqus 定义带立方根与系数：

```
Abaqus INV3 = ( 9/2 · S·S·S )^(1/3) = ( 27/2 · J₃ )^(1/3)
```

已改为 `np.cbrt(13.5 · J₃)`（量纲应力¹，J₃<0 时结果为负，符号保留）。

### ② 主应力 —— 公式正确，节点处口径保持现状（待确认）

主应力用全张量特征值计算，数学上正确。差异仅在**外推位置**：

- **积分点（INTEGRATION_POINT）**：直接从张量算，两边一致。
- **单元节点 / 节点（ELEMENT_NODAL / NODAL）**：
  - 我们：先把张量外推到节点，再算不变量（**方法 B**）。
  - Abaqus 云图默认：先在积分点算好标量不变量，再外推该标量（**方法 A**）。
  - 对主应力这类非线性量，两者在节点上**本就有差**（方法 A 会过冲）。

→ 这是口径选择，不是算错。**当前保持方法 B**（节点处先外推张量再算不变量）。
若改完后主应力仍对不上，下一步就改成方法 A（先算标量再外推）。

### ③ 所有 Abs 变体 —— 已修正为「带符号」✅

Abs 云图里**存在负值**：Abaqus「Max. Principal (Abs)」挑绝对值最大的主值，
但**保留原符号**。已改为：

```
MAX_PRINCIPAL_ABS         = λ₃  若 |λ₃| ≥ |λ₁|，否则 λ₁      （保留符号）
MAX_INPLANE_PRINCIPAL_ABS = 面内max 若 |面内max| ≥ |面内min|，否则 面内min
```

实现用 `np.where(np.abs(a) >= np.abs(b), a, b)`。另外把 `MAX_PRINCIPAL_ABS`
也设为 numpy 专属，使积分点不再走可能「无符号」的 `getScalarField`，三个位置
（IP / EN / NODAL）统一带符号、口径一致。

> 备注：早前 door 模型探测时 `getScalarField(MAX_PRINCIPAL_ABS)` 值域恰为
> `[0, 7.764]`，是因该模型受载区一直拉应力主导（绝对值最大者始终是正的 λ₃），
> 没触发翻负号，被误判为「无符号」。实为带符号。

### ④ 应变场切应变分量 —— 已修正（÷2）✅

Abaqus 应变场（E/LE/NE/PE/EE/IE/THE/CE/VE/SE）剪切分量是**工程剪应变**
`γ₁₂ = 2·ε₁₂`。`_compute_invariants_numpy(comp, inv, is_strain=True)` 现对应变场
先 `c12,c13,c23 ÷ 2` 还原成张量剪应变 ε，再算主应变/Tresca/INV3/面内/Abs。
应力场 `is_strain=False`，不除。

- 应变类场清单（领导：先全算，再校对）：`E,LE,NE,PE,EE,IE,THE,CE,VE,SE`，
  见 `_STRAIN_FIELDS`，需增删直接改这个集合。
- **Mises 只算应力**：应变场已从其不变量列表剔除 MISES，不再生成。

影响范围（修正前应变在以下位置偏大，现已对齐）：
- 积分点（IP）走 Abaqus `getScalarField` 的不变量本就正确；
- 单元节点 / 节点（EN / NODAL）numpy 重算，现已 ÷2；
- numpy 专属不变量（Abs）即便 IP 也由我方算，现已 ÷2。

## 一、分量约定（所有公式的前提）

输入张量分量顺序按 Abaqus 约定：

```
comp[0]=S11  comp[1]=S22  comp[2]=S33  comp[3]=S12  comp[4]=S13  comp[5]=S23
```

- **6 分量（实体单元）**：11, 22, 33, 12, 13, 23 全有
- **4 分量（壳 / 膜单元）**：只有 11, 22, 33, 12，此时令 **S13 = S23 = 0**
- 记号：`p = (S11+S22+S33)/3`（平均正应力）；偏量 `Sij_dev = Sij − p·δij`
- 主应力 `λ₁ ≤ λ₂ ≤ λ₃` = 下面对称张量 T 的特征值（`numpy.linalg.eigvalsh`，升序）：

```
        | S11  S12  S13 |
   T =  | S12  S22  S23 |     的特征值
        | S13  S23  S33 |
```

## 二、各不变量公式（代码原文）

| 不变量 | 代码公式 |
|---|---|
| **MISES** | `√( 0.5·[ (S11−S22)² + (S22−S33)² + (S33−S11)² + 6(S12²+S13²+S23²) ] )` |
| **PRESS**（压力） | `−(S11+S22+S33)/3` |
| **MAX_PRINCIPAL** | `λ₃`（最大特征值） |
| **MID_PRINCIPAL** | `λ₂` |
| **MIN_PRINCIPAL** | `λ₁`（最小特征值） |
| **TRESCA** | `λ₃ − λ₁` |
| **MAX_PRINCIPAL_ABS** | `max(\|λ₁\|, \|λ₃\|)`（无符号幅值，恒 ≥ 0） |
| **INV3**（第三不变量） | `det(S_dev)` = `d11·(d22·d33 − S23²) − S12·(S12·d33 − S23·S13) + S13·(S12·S23 − d22·S13)`，其中 `d11=S11−p, d22=S22−p, d33=S33−p` |
| **MAX_INPLANE_PRINCIPAL** | `(S11+S22)/2 + √( ((S11−S22)/2)² + S12² )` |
| **MIN_INPLANE_PRINCIPAL** | `(S11+S22)/2 − √( ((S11−S22)/2)² + S12² )` |
| **MAX_INPLANE_PRINCIPAL_ABS** | `max(\|面内max\|, \|面内min\|)`（无符号幅值，恒 ≥ 0） |
| **OUTOFPLANE_PRINCIPAL** | `S33`（面外方向直接取 S33） |
| **MAGNITUDE**（向量场用，如位移 U） | `√( Σ comp² )` |

## 三、两处待与 Abaqus 口径确认的点

### ① INV3 —— 可能存在定义不一致 ⚠️

当前代码 `INV3 = det(S_dev)`，即偏应力第三不变量 **J₃**。

而 Abaqus 输出变量中的 "Third Invariant" 定义带立方根与系数：

```
Abaqus INV3 = ( 9/2 · S·S·S )^(1/3) = ( 27/2 · J₃ )^(1/3)
```

即 Abaqus 报的是 `(27/2 · det(S_dev))` 再开三次方，量纲为应力¹；
我们目前只报 `det(S_dev)` 本身，量纲为应力³。**数值与量纲都对不上。**

→ 若按 Abaqus "Third Invariant" 口径，本条公式需改为 `(27/2 · J₃)^(1/3)`。等确认。

### ② 主应力 —— 公式正确，但节点处口径需对齐

主应力用全张量特征值计算，数学上正确。差异仅在**外推位置**：

- **积分点（INTEGRATION_POINT）**：直接从张量算，两边一致。
- **单元节点 / 节点（ELEMENT_NODAL / NODAL）**：
  - 我们：先把张量外推到节点，再算不变量（**方法 B**）。
  - Abaqus 云图默认：先在积分点算好标量不变量，再外推该标量（**方法 A**）。
  - 对主应力这类非线性量，两者在节点上**本就有差**（方法 A 会过冲）。

→ 这是口径选择，不是算错。需确认节点处采用方法 A 还是方法 B。

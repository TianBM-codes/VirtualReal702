# 通用求解接口与源码交付

本分支交付应用源码，允许使用开源组件。通用命名不代表已消除外部求解器的运行依赖，也不代表已完成任何特定平台认证。

## 功能范围

保留 INP、ODB、BDF、OP2、UNV 相关业务、结果显示、灵敏度分析和模型修正。移除 CDB/RST 专用解析器、数据库导入器、任务分支及对应安装依赖；新建项目不再接受这两种输入。旧队列中的对应任务会明确标记失败。已有标准 HDF5 工作区仍由通用读取链路处理。

移除原商业工具参考脚本，不改写其版权声明。自有代码、文件名、接口、配置、示例与说明统一使用通用名称；开源第三方实现不复制进源码交付包。

## 命名与兼容性

- `deck_solver` / `DeckSolver`：INP 输入与 ODB 结果工作流。
- `bulk_solver` / `BulkSolver`：BDF 输入与 OP2 结果工作流。
- `bulk_provider`：单独安装的开源 BDF/OP2 解析实现。
- `APP_DECK_SOLVER_CMD`、`BULK_SOLVER`：实际求解命令，部署时设置。默认通用命令仅是 PATH 上的启动入口，需要由部署方提供。

这是一项不兼容的接口命名变更。调用方需同步更新 URL、请求字段、任务类型、配置键及相关路径；当前仓库内的调用、测试和 API 示例同步更新。外部客户端不在本次源码交付范围内。旧数据库中已保存的求解器类型、任务类型、PBS 应用标识和配置 JSON 可能仍使用旧值，部署前需备份并按新接口映射迁移，不会自动修改生产数据；未完成迁移前应使用独立数据库和工作目录验证。

## 外部解析运行环境

主依赖文件不再声明带产品名称的可选解析包。BDF 快速几何路径不使用完整解析器时可继续工作；复杂卡片、OP2、设计卡生成等仍需单独安装与原解析 API 兼容的开源提供方（原兼容版本 1.4.1）。适配入口是配置化加载，并未重写第三方解析算法，也未消除这一可选依赖。部署方负责保留其原始许可证并安装在外部 Python 环境中，不将第三方安装目录包含在源码交付中。

运行前设置环境变量，或通过 `FEM_RUNTIME_CONFIG` 指向交付目录之外的 JSON 配置：

```json
{
  "FEM_BULK_PROVIDER_MODULE": "your_installed_reader_root",
  "FEM_RESULT_CONSTANTS_MODULE": "your_runtime_constants_module"
}
```

两个值均为真实 Python 模块名，不是求解器命令。第一项提供 `.bdf.bdf`、`.bdf.cards.materials`、`.op2.op2` 等既有子模块接口；第二项提供 `NODAL`、`ELEMENT_NODAL`、`MISES` 等运行时常量。第二项未指定时尝试使用结果读取 API `odbAccess` 导出的常量。环境变量优先于 JSON。不要在交付源码内填入机器专用配置。

完整解析器按功能延迟加载；缺少提供方时，相应功能明确报错。结果导出子进程和远程工作节点也要继承这些配置，并具有所需模块与许可证。

## 源码打包

使用 `git archive` 导出已提交版本；不要直接压缩工作目录，否则会带入本地配置、缓存、依赖目录或版本历史。本地 `AGENTS.md`、机器配置与 `.git` 不属于源码包。

原有 `src/l1/check.py` 是带本机路径且存在顶层缩进错误的临时检查片段，没有程序调用引用；保留在仓库中，通过导出属性排除出源码包，不将其当作可运行模块交付。

准备一份目录之外的策略 JSON，字段为 `deny_words`，数组填写实际禁止出现的词，然后执行：

```powershell
python tools/export_source.py --policy-file C:/delivery-policy.json --output C:/delivery/source.zip
```

工具仅使用标准库，扫描 ZIP 内所有文件路径和内容，不区分大小写，同时检查 UTF-8 与 UTF-16 字节；发现命中则停止，不生成源码包。第三方版权声明不能通过删改来通过扫描；如引入新的组件，应调整交付范围或替换实现。

## 验证方式

按仓库约定，本次不在代理机器执行测试。开发者配置外部运行环境后执行 `python -m pytest tests/ -v`，并验证模型导入、三维显示、结果查询、求解、灵敏度和模型修正的完整流程。接口全量改名尚需外部调用方联调，不能仅凭词语扫描认定功能已验证通过。

# 试验模态数据(UNV)导入指南

> 配套文档:《[同步动画页面测试步骤](同步动画页面测试步骤.md)》。
> 本文只讲"试验侧"数据怎么来、怎么导入、怎么确认导入成功。

## 1. 数据流向

```
UNV 文件 ──POST /import/unv──▶ MySQL t_mt_py_test_* 表 ──▶ /api/model/testMesh/* 接口
   │                              (节点/线元/频率/振型)        (含 syncAnimation)
   └─ 没有真实试验数据时,用 tools/gen_test_unv_from_op2.py 从 BDF+OP2 造一份
```

试验网格的所有页面显示都从 MySQL 读,所以**必须先导入 UNV**,testMesh 系列接口才有数据。

## 2. 前置条件

- `app.py` 已启动(默认端口 5000),MySQL 连接配置在 `service_config.json`(`DB_HOST/PORT/USER/PASSWORD/DATABASE`)。
- 决定一个**纯数字**的 project 编号(下文以 `1001` 为例)。
  **重要**:试验侧 MySQL 的 `pid` 是整数,FEM 侧 workspace 编号是字符串,同步动画要求两边用同一个号,所以创建 FEM project 时也必须用 `"1001"` 这种纯数字字符串。

## 3. 现成样例文件

仓库自带一份从 `sol103.bdf + sol103.op2` 生成的模拟试验数据:

```
tools/sol103_test.unv    (40 测点、59 条线框、8 阶模态,频率相对 FEM 有 ±3% 偏移)
```

拉最新代码后直接用它导入即可,不需要真实试验数据。

## 4. 导入

接口:`POST /import/unv`,`file_path` 填**服务器本地路径**(也支持 http URL,会先下载)。

```bash
curl -X POST http://127.0.0.1:5000/import/unv \
  -H "Content-Type: application/json" \
  -d '{
    "file_path": "D:/work/repo/tools/sol103_test.unv",
    "project_id": 1001,
    "clear_before_insert": true
  }'
```

| 字段 | 说明 |
|---|---|
| `file_path` | UNV 文件在**服务器上**的路径(Windows 注意用 `/` 或双反斜杠) |
| `project_id` | 整数,与 FEM project 同号 |
| `clear_before_insert` | `true`(默认)= 先清掉该 project 的旧试验数据再导入,重复导入用这个覆盖 |

成功返回 `code=200`,message "UNV 导入成功",data 里有导入的节点/单元/模态数量统计。

## 5. 确认导入成功

```bash
# 模态阶次下拉:应返回 Undeformed + 8 阶(EMA 1 ~ EMA 8,带频率)
curl -X POST http://127.0.0.1:5000/api/model/testMesh/modelSelect \
  -H "Content-Type: application/json" -d '{"project_id": 1001}'

# 几何:ids 应有 40 个,elementsIndex 非空
curl -X POST http://127.0.0.1:5000/api/model/testMesh/geometry \
  -H "Content-Type: application/json" -d '{"project_id": 1001, "order": 1}'
```

两个都有数据,试验侧就绪。

## 6. 自己生成 UNV(可选)

换别的 BDF/OP2 模型、或想调测点数/噪声时,用生成器重新造:

```bash
python tools/gen_test_unv_from_op2.py \
    --bdf /path/to/sol103.bdf \
    --op2 /path/to/sol103.op2 \
    --out /path/to/my_test.unv \
    --n-points 40 --modes 8 --noise 0.03 --freq-shift 0.03
```

| 参数 | 默认 | 说明 |
|---|---|---|
| `--n-points` | 40 | 测点数(最远点采样,自动在结构上均匀分布) |
| `--modes` | 8 | 导出前几阶模态 |
| `--noise` | 0.03 | 振型相对扰动(模拟测量误差) |
| `--freq-shift` | 0.03 | 频率随机偏移上限(±3%,模拟试验与仿真的频率差) |
| `--seed` | 702 | 随机种子,同种子结果可复现 |

要求:Python 3 + `pyNastran` + `numpy`(与主服务同环境即可);OP2 必须是 SOL103(含 eigenvectors)。脚本结束会用项目自己的 UNV 解析器回读校验,打印 `OK` 才算成功。

## 7. 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 导入报文件不存在 | `file_path` 是**服务器**视角的路径,不是浏览器本机路径 |
| modelSelect 返回只有 Undeformed | 导入时 `project_id` 和查询时不一致;或导入失败,看响应 message |
| 导入成功但 syncAnimation 报 FEM 不可用 | 试验侧没问题,是 FEM 侧 project 未就绪,见测试步骤文档第 2 步 |
| 想清掉重来 | 再导一次(`clear_before_insert: true` 覆盖) |

# 试验网格 / FEM 模型同步动画 — 页面测试步骤

> 目标:验证 `syncAnimation` 接口 + `viewer/modal-sync-demo.html` 页面上,
> 试验网格(橙色线框)与 BDF/OP2 仿真模型(蓝色)**同屏叠加、幅度一致、逐帧同步**地摆动。
>
> 试验数据导入的细节见《[试验数据导入指南](试验数据导入指南.md)》。

## 0. 环境准备(一次性)

| 项 | 说明 |
|---|---|
| 后端 | `python app.py`(端口 5000)+ `python src/job_runner.py`(或 `service_config.json` 里 `APP_EMBEDDED_RUNNER=1` 则不用单独起);Windows 直接 `start.bat` |
| MySQL | `service_config.json` 配好,能连上 |
| 模型文件 | `sol103.bdf` 和 `sol103.op2` 放到服务器任意目录(下文以 `D:/models/` 为例) |
| 前端 | `cd viewer && npm install && npm run dev`(端口 5173) |

下文统一用 project 编号 **`1001`**(必须纯数字,原因见导入指南 §2)。

## 1. 创建 FEM project(BDF 几何)

```bash
curl -X POST http://127.0.0.1:5000/api/projects \
  -H "Content-Type: application/json" \
  -d '{"project_id": "1001", "source_path": "D:/models/sol103.bdf"}'
```

然后轮询状态直到 `ready`(L1+L2 跑完,sol103 很小,一般几十秒内):

```bash
curl http://127.0.0.1:5000/api/projects/1001        # 看 status 字段
curl "http://127.0.0.1:5000/api/projects/1001/logs" # 卡住时看进度日志
```

## 2. 挂 OP2 模态结果组

```bash
curl -X POST http://127.0.0.1:5000/api/projects/1001/results \
  -H "Content-Type: application/json" \
  -d '{"source_path": "D:/models/sol103.op2", "result_group": "op2"}'
```

等解析完成(同样看 logs),确认结果目录里出现 FREQUENCY 步、12 阶模态:

```bash
curl http://127.0.0.1:5000/api/projects/1001/result-catalog
```

> 记住这里的 `result_group` 名(本例 `op2`),页面上要填。

## 3. 导入试验 UNV

```bash
curl -X POST http://127.0.0.1:5000/import/unv \
  -H "Content-Type: application/json" \
  -d '{"file_path": "<仓库路径>/tools/sol103_test.unv", "project_id": 1001}'
```

详见导入指南。

## 4. 接口冒烟(可选,页面异常时用来定位)

```bash
curl -X POST http://127.0.0.1:5000/api/model/testMesh/syncAnimation \
  -H "Content-Type: application/json" \
  -d '{"project_id": 1001, "order": 1, "result_group": "op2"}'
```

检查响应 `data`:

- `fem.available` 为 `true`(为 `false` 时 `fem.reason` 写明原因);
- `test.scaleFactor > 0`、`fem.scale > 0`,`test.frames` 有 20 组;
- `test.frequency`(约 462 Hz)与 `fem.frequency`(约 455 Hz)接近但不相等(试验数据故意加了 ±3% 偏移)。

## 5. 页面测试(主要环节)

打开:**http://localhost:5173/odb-viewer/modal-sync-demo.html**
(注意有 `/odb-viewer/` 前缀;这是独立 demo 页,不影响主 viewer。)

左侧面板依次填:

| 字段 | 填 |
|---|---|
| 后端地址 | `http://127.0.0.1:5000` |
| Project ID | `1001` |
| Result Group | `op2`(第 2 步创建时的名字) |
| 试验模态阶次 order | `1` |
| 其余 | 保持默认 |

点 **加载**,然后逐项核对:

### 5.1 加载正确性

- [ ] 状态区显示:`试验:40 测点,462.xx Hz`、`FEM:step=… 454.xx Hz`、两侧 scale、`同步:20 帧`;
- [ ] 无黄色 ⚠ 警告;
- [ ] 画面里蓝色 FEM 模型和橙色试验线框(黄点=测点)**叠在一起、位置吻合**(测点应落在 FEM 表面上,因为测点就是从 FEM 节点采样的)。

### 5.2 同步性(核心)

点 **播放**:

- [ ] 两个模型一起摆动,**节奏完全一致**(同时到达峰值、同时回零,无相位差、无漂移,盯 30 秒以上);
- [ ] 峰值时两者的最大摆幅**目测相当**(这就是统一 scale 的效果);
- [ ] 变形形状一致:试验线框跟着 FEM 表面一起动,只在细节上略有差别(试验数据带 3% 噪声,属预期);
- [ ] **暂停**:停在当前变形帧不回弹;**复位**:两模型同时回到未变形状态。

### 5.3 选项功能

- [ ] **换阶次**:order 改 2、3…8 分别加载,每阶都能同步播放,频率随阶次上升;
- [ ] **flip**:勾选后重新加载,试验线框反向摆(与 FEM 反相)——这是给振型符号相反时人工校正用的;
- [ ] **coefficient**:改 2.0 重新加载,两个模型的摆幅**同时**减半(比例仍一致);
- [ ] **FEM 帧号**:留空 = order-1(1 阶对 1 阶);显式填别的帧号(如 `3`)应看到 FEM 换成另一阶振型,与试验阶次错开——用于试验阶次与 FEM 阶次不一一对应的场景;
- [ ] **播放速度**:改 0.5 / 2.0,快慢变化但两模型仍同步。

### 5.4 降级场景(单独显示)

- [ ] order 填 `9`(试验只有 8 阶):状态区应提示试验振型缺失,不崩;
- [ ] Result Group 故意填错(如 `xxx`)再加载:状态区黄字 `FEM 不可用:…`,但**试验线框仍正常显示和播放**——对应"试验模型单独显示"的需求;
- [ ] order 填 `0`:显示未变形状态,播放无动作(预期)。

## 6. 常见问题排查

| 现象 | 原因 / 处理 |
|---|---|
| 加载失败:Failed to fetch | 后端地址错 / app.py 没起 / 端口不对。F12 看 Network |
| `FEM 不可用:FEM workspace '1001' 未加载` | project 未到 `ready`;或服务刚重启,L3 后台线程还没把 workspace 载入内存,等十几秒重试 |
| `FEM 不可用:没有 FREQUENCY(模态)步` | OP2 结果组没挂上,或页面 Result Group 名填错(必须与第 2 步一致) |
| `FEM 模态帧 x 超出范围` | order 超过 FEM 模态阶数(sol103 有 12 阶),或 FEM 帧号填错 |
| 试验线框不出来 / 只有 Undeformed | UNV 没导入或 project_id 不一致,见导入指南 §7 |
| 两模型位置对不上 | 试验数据不是从这套 BDF/OP2 生成的(测点坐标来自别的模型);确认 UNV 与 project 用的是同一对 BDF/OP2 |
| 页面 404 | URL 少了 `/odb-viewer/` 前缀,或 `npm run dev` 没起 |

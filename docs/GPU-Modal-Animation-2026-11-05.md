# 模态动画改为前端 GPU 计算

后端继续解析 OP2 并按阶准备顶点位移（modal-shape 与 vertex-displacements 共用）；前端用原始坐标、位移和实时相位计算动画。

全量预热不再生成每阶 20 帧 modal-animation 响应包，调用计数相应减少。现有按需接口保留兼容；已生成的旧磁盘缓存不主动删除。计划覆盖范围缩小，因此 PLAN_VERSION 仍为 3，不强制已完成项目重新预热。已在运行的旧进程需重启后才能使用新计划。

静态变形坐标、云图和建议倍率预热保持原行为。测试更新为检查 FREQUENCY 步每阶位移仍被准备，且不再调用多帧动画合成。按仓库约定，本机未运行后端测试。

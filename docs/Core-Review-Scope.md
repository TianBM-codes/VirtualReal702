# 核心功能简化版

本分支基于通用命名源码版本，按用户指定范围裁剪。它保留已有核心计算实现及其数据准备链路，并不代表已经取得保密或平台兼容认证。

## 保留范围

| 功能 | 保留的数据与处理链路 |
| --- | --- |
| 求解器调用 | 本机命令配置、输入文件生成、异步任务状态、求解及结果解析入库 |
| 灵敏度分析 | 参数和响应配置、输入生成、矩阵计算/导入、结果查询与显示 |
| 模型修正 | 静力与模态修正、参数约束、迭代计算及结果写回 |
| 变形显示 | 三维网格、位移结果、变形及模态动画、试验网格同步显示 |
| 节点匹配 | 试验测点导入、单位与坐标配置、节点/自由度匹配、匹配结果查询 |
| 模态匹配 | 试验/仿真模态导入、相关性计算、模态配对与修正所需响应配置 |

模型导入、SQLite 工作区索引、业务数据库、结果查询、项目配置与后台任务是这些功能的共同基础，继续保留。加载级试验数据导入和测点曲线仍服务于静力匹配；UNV 解析器中的共享数据读取逻辑继续保留，不单独提供 FRF 曲线展示接口。

## 本分支移除内容

- 远程集群提交、轮询及对应请求模型和实现模块；求解器调用保留本机执行路径。
- 第三方服务兼容查询、外部服务加载级对比及相关客户端、示例与测试。
- FRF 曲线展示、独立试验结果 JSON/VTK 导出接口；修正与灵敏度所需的结果导出仍保留。
- 独立重复修正脚本、性能基准入口、模拟服务器、诊断工具与历史实测材料。
- 与本版范围无关的历史方案、演示页面和旧 API 集合。

这是实际源码裁剪，不通过开关隐藏旧路由。未使用的数据库驱动声明已移除，仅保留实际使用的连接器；公共计算、解析及可视化依赖保持原版本。

## 页面和日志

`/static/viewer.html` 和 `/static/modal_viewer.html` 的网址保持不变，文件移至专用 `static/` 目录。服务不再把整个 `tools/` 源码目录作为静态资源发布。Vue 主页面及同步显示模块保留，性能基准和独立演示构建入口移除。

HTTP 计时中间件与通用请求日志只记录方法、路径、状态和耗时等元数据，不读取或打印请求正文、查询参数。求解过程日志和业务结果记录仍用于状态追踪；此改动不等同于完整的日志脱敏、鉴权或保密认证实现。

## 启动与验证

安装根目录 `requirements.txt`，按 `service_config.example.json` 准备本机配置；外部解析提供方和求解命令配置见 [源码适配说明](Source-Delivery-Adaptation.md)。保留原有数据库结构和配置方式，不清空已有数据。

```powershell
python app.py
python src/job_runner.py
```

Windows 默认关闭内置解析进程，因此需在两个终端分别运行以上命令。其他环境启用内置解析进程时，不重复启动独立任务进程。

接口索引见 [Core-API-Index.md](Core-API-Index.md)，参数模型以 OpenAPI `/openapi.json` 和源码为准。`app.py` 是包含匹配和计算的完整入口；单独启动 `src.l3.main:app` 仅提供可视化接口。

按仓库约定，不在代理机器运行测试。开发者执行 `python -m pytest tests/ -v`，并依次验证：导入模型和试验数据 → 节点匹配 → 模态匹配 → 本机求解 → 灵敏度分析 → 模型修正 → 变形显示。导出源码前使用外部禁词策略扫描，操作见源码适配说明。交付 ZIP 不包含版本历史、机器配置、模型数据或第三方安装目录。

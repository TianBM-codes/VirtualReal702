# 模型修正接口清单

## 配置

- Abaqus 可执行路径不走单独接口，后端在调用前优先读取 `service_config.json` 中的 `APP_ABAQUS_CMD`
- 如果请求体显式传了 `abaqus`，则以请求值覆盖默认配置

## 参数与响应录入

### 接口: `POST /add/response`

- 接口含义: 手工录入一个模型修正响应
- 功能说明: 用于补充或维护响应定义，保存响应类型、自由度、分析步和离散度
- 参数:
  - `project_id`: `int`，项目 ID
  - `type`: `string`，响应类型
  - `scatter`: `float`，离散度
  - `dof`: `string`，自由度
  - `step`: `string | null`，分析步，可空
- 返回样式:

```json
{
  "project_id": 101,
  "type": "DISPLACEMENT",
  "scatter": 0.1,
  "dof": "UX",
  "step": "Step-1"
}
```

## INP 与参数目录

### 接口: `POST /import/inp/catalog`

- 接口含义: 导入 INP 模型并建立模型修正基础目录
- 功能说明: 解析 INP 文件，将参数定义、参数目标、设计响应、支持的修正参数类型、可用 set 能力目录以及节点缓存写入数据库
- 参数:
  - `file_path`: `string`，INP 文件路径
  - `project_id`: `int`，项目 ID
  - `clear_before_insert`: `bool`，是否清理旧数据
  - `build_octree`: `bool`，是否构建节点缓存
  - `force_rebuild_octree`: `bool`，是否强制重建节点缓存
- 返回样式:

```json
{
  "file_path": "D:/demo/model.inp",
  "project_id": 101,
  "material_count": 2,
  "isotropic_material_count": 2,

  "design_responses_preview": [],
  "supported_quantities_preview": [],
  "quantity_set_capabilities_preview": []

```

### 接口: `POST /catalog/inp/parameter-options`

- 功能说明: 基于已导入的 INP 目录，返回可选参数、支持层级以及每个层级下可选的 set 名称，供前端参数联动选择
- 参数:

### 接口: `POST /optimization/parameter/create`

- 接口含义: 创建一个正式参与优化的参数
- 功能说明: 根据参数类型、层级和 set 选择结果，生成后续灵敏度分析和 Bayesian 模型修正使用的优化参数记录
- 参数:
  - `project_id`: `int`，项目 ID
  - `candidate_code`: `string | null`，候选参数编码，可空
  - `quantity_code`: `string | null`，参数类型编码，可空
  - `selection_mode`: `string | null`，参数层级，`GLOBAL` 或 `LOCAL`
  - `set_name`: `string`，选中的集合名称
  - `parameter_name`: `string | null`，参数名，可空
  - `scatter`: `float | null`，离散度，可空
  - `description`: `string`，描述，可空
  - `set_type`: `string | null`，集合类型，可空
  - `set_scope`: `string | null`，集合范围，可空
  - `instance_name`: `string | null`，实例名，可空
  - `part_name`: `string | null`，零件名，可空
- 返回样式:

```json
{
  "project_id": 101,
  "quantity_code": "E",
  "selection_mode": "GLOBAL",
  "set_name": "SET_A",
  "set_scope": "PART",
  "set_type": "ELSET",
  "created_parameter_count": 1,
  "created_parameters_preview": [
    {
      "parameter_name": "E_GROUP",
      "element_label": null,
      "current_value": 210000.0
    }
  ]
}
```

## 节点匹配与一致性评价

### 接口: `POST /pair/node_point`

- 接口含义: 进行试验测点与有限元节点的匹配
- 功能说明: 将试验测点坐标与 FE 节点坐标对齐，支持自动平移或手工变换，并保存匹配关系供后续一致性评价和模型修正使用
- 参数:
  - `project_id`: `int`，项目 ID
  - `max_distance`: `float | null`，最大匹配距离，可空
  - `overwrite`: `bool`，是否覆盖旧结果
  - `auto_translate`: `bool`，是否自动平移
  - `translation`: `number[3] | null`，手工平移向量，可空
  - `rotation`: `object | null`，手工旋转信息，可空
- 返回样式:

```json
{
  "project_id": 101,
  "node_match_count": 120,
  "transform": {
    "mode": "icp"
  },
  "matches_preview": []
}
```

### 接口: `POST /get/pair_node_point_result`

- 接口含义: 查询测点匹配结果
- 功能说明: 返回当前项目测点与 FE 节点的匹配明细，用于前端显示和联调核对
- 参数:
  - `project_id`: `int`，项目 ID
- 返回样式:

```json
{
  "project_id": 101,
  "node_matches": []
}
```

### 接口: `POST /correlation/evaluate`

- 接口含义: 进行一致性评价
- 功能说明: 基于试验静力结果、FE 静力结果和节点匹配关系，计算 DAC、DSF，并生成误差分析结果
- 参数:
  - `project_id`: `int`，项目 ID
  - `load_case_no`: `int | null`，载荷工况号，可空
  - `result_no`: `int | null`，结果序号，可空
  - `components`: `string[] | null`，参与比较的分量列表，可空
  - `include_rotations`: `bool`，是否包含转角分量
- 返回样式:

```json
{
  "project_id": 101,
  "load_case_no": 1,
  "result_no": 1,
  "components": ["UX", "UY", "UZ"],
  "aligned_point_count": 30,
  "value_count": 90,
  "analysis_error_row_count": 90,
  "analysis_error_preview": [],
  "dac": 98.5,
  "dsf": 1.02,
  "extra": {}
}
```

## 灵敏度

### 接口: `POST /sensitivity/store/dsa`
### 接口: `POST /sensitivity/calculate`

- 接口含义: 执行灵敏度分析并存储结果
- 功能说明: 生成灵敏度分析输入，按需调用求解器，从 ODB 或工作区提取灵敏度矩阵，并将矩阵和元数据写入数据库
- 参数:
  - `project_id`: `int`，项目 ID
  - `batch_no`: `string | null`，批次号，可空
  - `input_inp`: `string`，输入 INP 路径
  - `output_dir`: `string | null`，输出目录，可空
  - `odb_id`: `string | null`，已加载 ODB 标识，可空
  - `base_url`: `string | null`，ODB 服务地址，可空
  - `workspace`: `string | null`，工作区路径，可空
  - `odb_path`: `string | null`，ODB 文件路径，可空
  - `step`: `string | null`，分析步，可空
  - `instances`: `string[] | null`，实例列表，可空
  - `field_prefix`: `string`，灵敏度场前缀
  - `response_component`: `string | null`，响应分量，可空
  - `position`: `string | null`，结果位置，可空
  - `aggregation`: `string`，聚合方式
  - `frame`: `int`，帧序号
  - `run_solver`: `bool`，是否调用求解器
  - `write_cloud_result`: `bool`，是否写入云图结果
- 返回样式:

```json
{
  "analysis_run_id": 12,
  "project_id": 101,
  "batch_no": "1",
  "case_name": "demo_case",
  "response_names": ["R1", "R2"],
  "parameter_names": ["P1", "P2"],
  "response_count": 2,
  "parameter_count": 2,
  "point_count": 4,
  "matrix": [
    [0.1, 0.2],
    [0.3, 0.4]
  ]
}
```

## 模型修正

### 接口: `POST /optimization/bayesian/run`

- 接口含义: 执行 Bayesian 模型修正
- 功能说明: 读取当前参数、响应、灵敏度矩阵和目标响应，执行参数更新迭代，必要时重新求解，并输出最终参数、跟踪过程和最终位移结果
- 参数:
  - `project_id`: `int`，项目 ID
  - `batch_no`: `int`，批次号
  - `input_inp`: `string`，输入 INP 路径
  - `target_responses`: `any`，目标响应
  - `parameter_scatter`: `any | null`，参数离散度，可空
  - `response_scatter`: `any | null`，响应离散度，可空
  - `output_dir`: `string | null`，输出目录，可空
  - `save_results`: `bool`，是否保存文件结果
  - `workspace`: `string | null`，工作区路径，可空
  - `odb_path`: `string | null`，ODB 文件路径，可空
  - `iterations`: `int`，迭代次数
  - `exit_diff_percent`: `float | null`，提前停止阈值，可空
  - `run_solver`: `bool`，是否迭代求解
  - `write_cloud_result`: `bool`，是否写入云图
- 返回样式:

```json
{
  "project_id": 101,
  "batch_no": 1,
  "input_inp": "D:/demo/model.inp",
  "output_dir": "D:/demo/model_bayesian",
  "save_results": true,
  "iterations": 2,
  "requested_iterations": 2,
  "stopped_early": false,
  "exit_diff_percent": null,
  "field_prefix": "d_U_",
  "response_component": null,
  "step": null,
  "instances": [],
  "final_updated_inp": "D:/demo/model_iter2.inp",
  "final_parameter_values": [1.1, 0.9],
  "parameter_columns": [],
  "response_rows": [],
  "iteration_results": [],
  "saved_artifacts": {},
  "cloud_result": null,
  "final_static_output": {}
}
```

### 接口: `POST /optimization/bayesian/check`

- 接口含义: 校核 Bayesian 更新计算过程
- 功能说明: 基于文本矩阵和响应输入验证 Bayesian 更新逻辑，适合调试公式、对比算法结果和做独立校验
- 参数:
  - `sensitivity_matrix`: `object`，文本矩阵配置
  - `model_response`: `object`，模型响应文本配置
  - `target_response`: `object`，目标响应文本配置
  - `parameter_names`: `string[]`，参数名称列表
  - `parameter_scatter`: `any | null`，参数离散度，可空
  - `response_scatter`: `any | null`，响应离散度，可空
  - `input_inp`: `string | null`，输入 INP，可空
  - `parameter_values`: `any | null`，参数当前值，可空
  - `damping`: `float`，阻尼
  - `step_scale`: `float`，步长
  - `lower_bound`: `any | null`，下界，可空
  - `upper_bound`: `any | null`，上界，可空
  - `output_dir`: `string | null`，输出目录，可空
  - `case_name`: `string`，案例名
- 返回样式:

```json
{
  "case_name": "bayesian_text_check",
  "parameter_names": ["P1", "P2"],
  "parameter_values": [1.0, 2.0],
  "model_response": [10.0, 20.0],
  "target_response": [9.5, 18.0],
  "sensitivity_matrix": [
    [0.1, 0.2],
    [0.3, 0.4]
  ],
  "bayesian": {
    "p_new": [1.05, 1.92]
  },
  "saved_artifacts": {}
}
```

# 模型修正代码目录说明

本次只整理模型修正主线代码，未修改以下两条主线：

- `src/l1`, `src/l2`, `src/l3` 的 ODB 三层可视化链路
- `src/modal_service` 的独立模态 JSON 服务

## 新目录

`services/model_update/`

- `analysis/`
  - `inp_service.py`
  - `sensitivity_service.py`
  - `solver_service.py`
- `importers/`
  - `bdf_service.py`
  - `unv_service.py`
- `solver_prep/`
  - `abaqus_sensitivity.py`
  - `abaqus_adjoint.py`
  - `nastran_sol103.py`

## 说明

### analysis

负责模型修正主业务流程，包括：

- INP 目录提取
- 测点匹配
- 自由度匹配
- 响应目录构建
- DAC / DSF 计算
- 本地求解器编排

### importers

负责外部数据导入，包括：

- BDF 导入
- UNV 试验模态导入

### solver_prep

负责求解前输入文件生成，包括：

- Abaqus 普通灵敏度输入文件生成
- Abaqus 壳厚 adjoint 输入文件生成
- Nastran `SOL103` 转换

## 兼容策略

原 `services/` 目录下的同名文件已改为兼容导出层，目的是：

- 不打断旧引用
- 给后续重构留过渡期
- 新开发统一指向 `services/model_update/`
